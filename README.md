# CodecTechnologies – Python Internship

This repository contains the two projects completed as part of my Python Development Internship at CodeTech Technologies.

## Task 1 – API Performance Monitor

The API Performance Monitor is a Python application used to check and analyze API performance.

### Features
- Measures API response time
- Tracks successful and failed API requests
- Calculates average response time
- Calculates API error rate
- Stores API data using SQLite
- Displays performance information using Grafana

### Technologies
- Python
- Flask
- Requests
- SQLite
- Grafana
- HTML
- CSS

### Outcome
This project helps identify slow APIs, API errors, and overall API performance through a simple monitoring system and Grafana dashboard.

## Task 2 – Smart Home Automation

The Smart Home Automation System is a Python-based application that simulates the control of smart home devices.

### Features
- Controls smart home devices
- Displays device status
- Uses MQTT for device communication
- Supports scheduled automation
- Stores data using SQLite
- Includes a virtual Raspberry Pi
- Provides a web-based control interface

### Technologies
- Python
- Flask
- MQTT
- SQLite
- HTML
- CSS
- JavaScript
- Scheduler

### Outcome
This project demonstrates how IoT concepts can be used to control and automate smart home devices without requiring physical hardware.
